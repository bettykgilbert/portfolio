New Hire Onboarding Agent: Northstar Card Services

Built by Betty K Gilbert · October 2026

Working demo. Northstar Card Services is a fictional credit card issuer. Step 1 assigns a real ID and email in your browser. Step 2 is an AI agent that drafts a full onboarding plan for a hiring manager to approve. No real accounts are created and nothing is sent.

About the AI step. Step 1 works for everyone. Step 2's AI agent runs live in Claude, which this public page can't connect to, so here it shows a recorded example run that uses the same rules. Want to see the agent work live? I'm happy to run it for you on a call.

    Guardrails: the AI drafts, the rules decide

    The agent handles the judgment calls. Anything that affects security, compliance, or dates is enforced by fixed rules in the workflow, so a wrong guess or a strange job title can't grant access or skip required training.

    The AI decidesThe rules enforce
    Which approved role profile fits the job title, and whyAccess comes only from that profile's approved list
    When a title is unclear, sends it to HR instead of guessingAn unknown profile blocks access until HR assigns one
    Which role-specific courses to assignAll 6 mandatory compliance courses are always added
    The first 30 days and the welcome emailDue dates come from the business calendar, skipping weekends and holidays
    Nothing is sent by the AIPayment, card-data, and admin access need a second approver, and the manager approves every plan

    From demo to production

    What it replaces

    • Separate emails or tickets to HR, IT, and Training for every new hire
    • Managers guessing which systems and courses a role needs
    • Hand-typed IDs and emails that clash or contain typos
    • Welcome emails and 30-day plans written from scratch each time

    To run it for real

    • Keep the ID counter, role profiles, and log in a shared list (SharePoint or Dataverse)
    • Run the agent in Copilot Studio or Power Automate with the same tools and guardrails
    • On approval, open the IT access ticket, enroll courses in the learning system, and send the email
    • Track days to ready, hires with full access on day 1, and HR touches per hire
